# FICBank — Remote Access Control (Part B)

📄 **Project Report:** [View Full Report](https://github.com/Viney-Washington/FICBank---Remote-Access-Control-Part-B/blob/main/Viney%20Washington_%20Part%20B%20Remote%20Access%20Control.pdf)

## Overview
This project focuses on implementing and testing secure remote access controls within a financial environment. The objective was to strengthen access security for remote users while protecting sensitive financial systems and data.

## Key Objectives
- Implement secure remote access using SSH and RDP
- Configure firewall rules to restrict unauthorized access
- Apply cryptographic controls to protect data in transit
- Analyze network traffic to validate secure communication
- Align access controls with NIST security standards

## Tools & Technologies
- SSH (Secure Shell)
- RDP (Remote Desktop Protocol)
- Firewall configuration (UFW / network rules)
- Wireshark (network traffic analysis)
- Cryptographic protocols (encryption for secure sessions)

## Implementation & Analysis
- Configured secure remote access using SSH with restricted user access
- Implemented RDP controls with security considerations for remote connections
- Applied firewall rules to limit access to authorized ports and IP ranges
- Analyzed network traffic to verify secure connections and identify risks
- Evaluated effectiveness of controls against potential attack vectors

## Security Considerations
- Enforced least privilege access for remote users
- Reduced attack surface by restricting open ports
- Secured communication channels using encryption
- Monitored network behavior for anomalies

## Outcome
The implementation improved the overall security posture of remote access by reducing unauthorized access risks and ensuring secure communication aligned with industry standards.
